Chipmunk BASIC for GEM
======================

Chipmunk BASIC 1.36 as a GEM program
with a resizable window, based on the
control panel CPX-BASIC.

Why?
----

Chipmunk BASIC was only ever ported to
the ST as the interpreter that drives
CPX-Basic. Honestly, I can't blame the
original developers of CPX-Basic. There
are plenty of great BASIC interpreters
for the Atari, but only one CPX-Basic.

But I wondered if I could generate a
stand-alone version together with the
CPX in one compile run. This is the
result. This BASIC will not replace your
Omikron, nor will it ever perform as
good as GFA-Basic.

Chipmunk vs. CPX
----------------
Chipmunk is a regular GEM app, 
distributed in three flavors for
68000, 68020-060 and the FireBee. Start
it up and you'll be greeted by a GEM
window. Everything happens in this
window. Since XControl's limit for the
window size doesn't exist for regular
GEM programs, there's much more room
for programs and their output.

When I first used Chipmunk, I
noticed that line editing would be 
a neat thing to have. It's now in
CPX-Basic as well.
